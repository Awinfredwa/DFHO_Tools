四面相同展开处理器 - 使用说明
==============================

这个脚本将处理图片并生成四面相同的展开版本，然后创建对应的PowerPoint演示文稿。

目录结构：
---------
四面相同展开.py         - 主处理脚本
单页模板.pptx           - PowerPoint模板文件  
原图/                   - 放置要处理的原始图片
成果/                   - 输出的PPTX文件将保存在这里

使用步骤：
---------
1. 将要处理的图片文件放入"原图"文件夹中
   - 支持格式：JPG, PNG, BMP, TIFF, WEBP
   - 可以放置多张图片，每张图片会单独处理

2. 确保"单页模板.pptx"文件在脚本同一目录中
   - 这是PowerPoint模板，脚本会为每张图片创建一个副本

3. 双击运行"四面相同展开.py"
   - 脚本会自动扫描"原图"文件夹
   - 显示找到的图片数量
   - 询问是否开始处理

4. 处理完成后，在"成果"文件夹中查看结果
   - 每张原始图片会生成一个对应的PPTX文件
   - 文件名格式：[原图名称].pptx

展开逻辑：
---------
脚本会将原始图片展开为2x2大小（四倍面积），四个象限完全相同：

┌─────────┬─────────┐
│ 左上角  │ 右上角  │
│ 原图复制 │ 原图复制 │
├─────────┼─────────┤
│ 左下角  │ 右下角  │
│ 原图复制 │ 原图复制 │
└─────────┴─────────┘

这与带旋转的展开方式不同，四面相同展开适用于：
- 对称设计图案
- 需要完全一致效果的产品
- 简单重复模式

图片映射配置：
--------------
脚本使用硬编码映射来决定哪些图片替换PowerPoint中的哪些形状：

默认配置：
- 原始图片 → 替换名为 "1" 的形状
- 展开图片 → 替换名为 "2" 的形状

如需修改映射：
1. 打开 四面相同展开.py 文件
2. 找到 IMAGE_SHAPE_MAPPING 配置部分
3. 修改形状名称列表以匹配您的PowerPoint模板
4. 保存文件

示例配置：
IMAGE_SHAPE_MAPPING = {
    "original": ["原图形状", "另一个原图形状"],
    "unfolded": ["展开图形状", "大图形状"]
}

注意事项：
---------
- 确保图片文件格式正确
- 处理过程中会创建临时文件，完成后自动删除
- 如果出现错误，检查图片文件是否损坏
- PowerPoint模板中需要有对应名称的图片形状
- 每个PPTX使用两张图片：原图和展开图

故障排除：
---------
1. 如果找不到图片：检查文件格式和位置
2. 如果PowerPoint处理失败：检查模板文件是否正确
3. 如果程序无法运行：确保安装了所需的Python库（PIL, python-pptx）
