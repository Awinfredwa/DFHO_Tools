🧾 餐巾纸展开处理器 - 使用说明
=========================

此工具可自动将单张图片展开为完整的餐巾纸图案。

📋 快速入门指南：
===============

1. 整理您的文件：
   - 为每个餐巾纸设计创建子文件夹
   - 每个子文件夹只放入一张图片（代表餐巾纸的右下角）
   - 支持格式：JPG, PNG, BMP, TIFF, WEBP

2. 运行处理器：
   - 双击"餐巾纸展开.bat"
   - 或直接运行"餐巾纸展开.py"
   - 等待处理完成

📁 文件夹结构示例：
=================

您的主文件夹应该如下所示：

📁 餐巾纸展开/
├── 🚀 餐巾纸展开.bat
├── 🐍 餐巾纸展开.py
├── 📝 README - 使用说明.txt
├── 📁 设计_A/
│   ├── pattern.jpg（输入 - 右下角图案）
│   └── pattern_unfolded.jpg（输出 - 完整展开图）
├── 📁 设计_B/
│   ├── flower.png（输入）
│   └── flower_unfolded.png（输出）
└── 📁 设计_C/
    ├── logo.jpg（输入）
    └── logo_unfolded.jpg（输出）

🎨 展开原理：
===========

输入图片被视为餐巾纸的右下角部分，脚本会自动生成4倍大小的完整图案：

    ┌─────────┬─────────┐
    │ 左上角  │ 右上角  │  ← 新的2倍宽度
    │ 双镜像  │ 垂直镜像 │
    ├─────────┼─────────┤
    │ 左下角  │ 右下角  │
    │ 水平镜像 │  原图   │  ← 新的2倍高度
    └─────────┴─────────┘

镜像说明：
- 右下角：原图（输入图片）
- 左下角：水平镜像（左右翻转）
- 右上角：垂直镜像（上下翻转）
- 左上角：双向镜像（180度旋转）

🔧 系统要求：
===========

- Python 3.6或更新版本
- PIL/Pillow 库（图片处理）
- 支持的操作系统：Windows, macOS, Linux

📝 重要提示：
===========

✅ 要求：
   - 每个子文件夹只能包含一张图片
   - 图片文件名可以任意（支持中文）
   - 支持多种图片格式

⚡ 输出：
   - 生成的文件名：[原文件名]_unfolded[扩展名]
   - 输出尺寸：原图的4倍面积（2倍宽度 × 2倍高度）
   - 保持原图质量，使用高质量保存设置

❌ 脚本将跳过：
   - 包含多张图片的文件夹
   - 不包含图片的文件夹
   - 已处理过的文件夹（已有_unfolded文件）

🆘 故障排除：
===========

问题："未找到包含单张图片的子文件夹"
解决方案：确保每个子文件夹只包含一张图片文件

问题："处理图片时出错"
解决方案：检查图片文件是否损坏，或格式是否支持

问题："未安装Python"
解决方案：从 https://www.python.org/downloads/ 下载Python
         安装时确保勾选"将Python添加到PATH"

问题："缺少PIL/Pillow库"
解决方案：在命令行运行：pip install Pillow

💡 使用技巧：
===========

1. 输入图片质量：
   - 使用高分辨率图片获得最佳效果
   - 确保图片边缘干净，适合镜像处理

2. 图案设计：
   - 设计时考虑镜像效果
   - 避免包含文字（镜像后会变成反字）
   - 适合对称或半对称图案

3. 批量处理：
   - 可同时处理多个文件夹
   - 已处理的文件夹会自动跳过
