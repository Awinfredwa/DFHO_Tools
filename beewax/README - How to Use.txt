🐝 蜂蜡布图片处理器 - 使用说明
===========================

此工具可自动处理您的图片并创建PowerPoint演示文稿。

📋 快速入门指南：
===============

1. 首次设置：
   - 双击"配置环境.bat"安装所需软件
   - 只需执行一次！

2. 整理您的文件：
   - 将您的PowerPoint模板文件（.pptx）放在此文件夹中
   - 为每个产品/设计创建子文件夹
   - 每个子文件夹必须包含这4个PNG文件：
     • 1-1L.png（大号 - 已调整尺寸）
     • 1-2M.png（中号 - 已调整尺寸） 
     • 1-3S.png（小号 - 已调整尺寸）
     • 2.png（源图片 - 将用于创建2-1L、2-2M、2-3S）

3. 运行处理器：
   - 双击"替换蜂蜡布.bat"
   - 等待处理完成

🔧 系统要求：
===========

- Windows电脑
- Python 3.6或更新版本
- 互联网连接（用于首次设置）
- 每个产品文件夹必须有确切的4个输入PNG文件名

📝 重要提示：
===========

✅ 必需输入：每个产品文件夹必须包含这些文件：
   - 1-1L.png（大号已调整尺寸）
   - 1-2M.png（中号已调整尺寸）
   - 1-3S.png（小号已调整尺寸）
   - 2.png（自动调整尺寸的源图片）

⚡ 生成输出：脚本自动从2.png创建这些文件：
   - 2-1L.png（从2.png中心裁剪33x35厘米）
   - 2-2M.png（从2.png中心裁剪25x28厘米）  
   - 2-3S.png（从2.png中心裁剪18x20厘米）

🎯 智能图片处理：
   - 脚本会自动检测2.png的尺寸
   - 如果图片太小，会智能放大到所需尺寸
   - 使用高质量LANCZOS算法保持图片清晰度
   - 支持任何尺寸的2.png输入文件！

❌ 脚本将跳过缺少任何4个输入文件的文件夹

🔧 PowerPoint设置：
==================

在您的PowerPoint模板中，确保您有命名的图片形状：

输入文件（您提供）：
- "1-1L"用于1-1L.png
- "1-2M"用于1-2M.png
- "1-3S"用于1-3S.png
- "2"用于2.png

生成文件（脚本创建）：
- "2-1L"用于2-1L.png（从2.png生成的大号）
- "2-2M"用于2-2M.png（从2.png生成的中号）
- "2-3S"用于2-3S.png（从2.png生成的小号）

在PowerPoint中检查/更改形状名称：
1. 选择图片
2. 右键点击 → "选择窗格"
3. 重命名形状以精确匹配（区分大小写）

🆘 故障排除：
===========

问题："缺少必需的输入文件"
解决方案：确保每个产品文件夹都有所有4个输入文件：
         1-1L.png, 1-2M.png, 1-3S.png, 2.png（确切名称！）

问题："源图片尺寸过大"
解决方案：这个问题已解决！脚本现在会自动放大过小的图片
         任何尺寸的2.png都可以工作

问题："未安装Python"
解决方案：从https://www.python.org/downloads/下载Python
         安装时确保勾选"将Python添加到PATH"

问题：脚本不工作
解决方案：1. 首先运行"配置环境.bat"
         2. 确保您的template.pptx在主文件夹中
         3. 检查PNG文件名是否完全正确

问题：PowerPoint中没有替换图片
解决方案：确保PowerPoint中的形状名称完全匹配：
         输入：1-1L, 1-2M, 1-3S, 2
         生成：2-1L, 2-2M, 2-3S
         （区分大小写，无空格）
